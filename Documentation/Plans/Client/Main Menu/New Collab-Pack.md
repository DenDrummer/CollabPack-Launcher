A button which'll open to open a menu to add a new CollabPack Connection
## V1
assuming the game can only be Minecraft
### Local Mods Folder
the folder to sync the mods to

e.g. `%APPDATA%/.minecraft/mods`
### Game Executable
location of the executable of the game
### Server Address
ip of the server
### Server Port
Optional if server uses default [[server port]]
### Username
username you'll use on this server, does not need to be the same as in-game name or name on other server.
### Identification
like a password or public SSH key
So others can't add mods in your name
will need to look into what the most secure way is that "your grandma could understand how to use" and for a way to prevent man in the middle attacks
