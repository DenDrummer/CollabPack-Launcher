The visibility of mods that others have added.
## Full
Users see all mods that have been added to the modpack from within the launcher.
They can also see who added the mod.
## Limited
Users see all mods from within the launcher, but not who added which mod unless they added it themselves.
## Count
Users only see the mods they added themselves from within the launcher, and a count of how many mods each other user has added.
## Private
Users only see the list of mods they added themselves.
