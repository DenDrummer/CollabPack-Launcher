## Classic
People can suggest which mods to add to the pack, but the CollabPack server admin/staff still needs to approve every single mod.
## Democracy
Idea for later expansion.

Whenever someone suggests a mod, it requires some votes before it gets added to the queue.

Obviously requires the configuration of [[mod visibility]] to be set so others can at least see which mods have been added.
## Chaos
If a mod is suggested and it meets all checks (e.g. the game can still open a world with it installed), it's automatically added.
