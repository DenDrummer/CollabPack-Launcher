## How to Use the Documentation
As mentioned in the root README.md, this documentation is the vault of an Obsidian vault.
If you're unfamiliar with Obsidian Notes, I highly recommend looking it up.
Essentially, all files are markdown files, so can be opened in any text editor, but you get more out of the notes using Obsidian. For example by linking notes and seeing their connections in its graph view.
